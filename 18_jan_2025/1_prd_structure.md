# PRD (Product/Project Requirement Document)
- Before creating any project must create a PRD, because it will enhance to understand from which point to start project and how to write code and many more through this PRD we can track our project as how much project is completed and remaining how much pending, what are the requirement for this project and many more.

# Making PRD for project-Online Juice Shop


## Objective
Build a HTML website for juice shop, take this offline juice shop to online.


## Scope
- What is in scope? / What is not in scope?

Build basic skeleton with card and contact detials of juice shop.

We will not add any payment sytem in this version.

## Features and Requirements
### P1
- pictures of juice
- price of juice

### P2
- pay with bitcoin

## User Stories or Use cases
User Story: 

User story means user kya kar saktey hey iss website se ya iss application se so basically user ki perspective keliye.
- mein chahta hum ghar beth kar juice order kar sakta hun.
- mujhey sabhi juice ki price rate chahiyeh with ml. 
- mujhey har juice ki image chahiyeh uske sath kya kya ingredients mix kiya hey jo juice me order karna chahta hun wo bhi mention hona chahiyeh.

## Technical Requirements
- HTML, CSS, JS

## Design Requirements
- kaisey image rakhna hey
- theme kis type ka rakhna hey
- button style kaisa rehna hey
- page ki background color kaisa rakhna hey
- Nav bar kaisey rakhna hey

## Timeline
Timesline means yeh jo project me kitna din me banakar dunga client ko 6month or 1year or 2year etc.
